# What is MultiThreading?
  MultiThreading in Java refers to the ability of a java program to execute multiple thread concurrently, allowing it to perform multiple tasks concurrently in parallel.

# What is Thread?
  A Thread is a lightweight process that has its own execution path and shares the same memeory space as the parent process, allowing for efficient communication and synchronization between threads.
